FONTLOG for Lowie
=================

This file records the history of Lowie and the people who worked on it.
It is a companion to the SIL Open Font License (OFL.txt).


Basic font information
----------------------

Lowie is a connected serif drawn as hand-poke tattoo dots. Every lowercase
letter joins the next. The joins are chosen automatically from each pair of
neighbouring letters (OpenType contextual alternates, the calt feature, on by
default in most apps). b, o, r, v and w hand over along the top, as in
handwriting; the rest join from the foot.

Three styles:
- Poke: loose, scattered dots with a ragged edge, as in hand-poke work.
- Poke Shaded: a dense edge with lighter dot shading inside.
- Poke Line: the outline only, as line work.

Stylistic set 1 (ss01, "All low joins") makes every letter join from the foot.

Character set: a to z and A to Z, accented letters for Dutch, French, German,
Spanish and Portuguese, figures 0 to 9, punctuation, curly quotes, ¡ ¿ and
common symbols (@ # % & £ € $ + − = × < > * _ – — | \ [ ] … ° ^ ~ ·).

Lowie is a display font. Use it at 30px and above. Each build places the dots
with a fixed random seed, so a given version always looks the same.

The outlines are generated by build scripts (source/build.py) with fontTools
and skia-pathops.


Changelog
---------

0.4 (2026-11-07)
- Poke back to the 0.2 design. The clumped look on the website header
  came from the browser faking a bold weight, not from the dots; the
  site no longer does that. If you set Lowie on the web, use
  font-weight: 400 and font-synthesis: none.

0.3 (2026-11-07)
- Poke redrawn again: smaller dots that never touch. In 0.2 the dots
  overlapped, which merged them into clumps with sharp notches at large
  sizes. Lighter on the page; reads best from about 40px.

0.2 (2026-11-06)
- Poke redrawn: bigger dots scattered at random, with a loose edge row
  instead of a traced outline. Reads as dots from smaller sizes and the
  file is half the size. The 0.1 look stays in the source as Poke Classic.

0.1 (2026-11-06)
- First release candidate: Poke, Poke Shaded and Poke Line.
